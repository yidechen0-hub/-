## 2. Unresolved reference 'CydPluginDemoJNI'

在`CydPluginDemoPlugin`中显示这个问题，最终发现是`CydPluginDemoJNI`未编译成功。

**确认 `CydPluginDemoJNI` 类是否被编译**

`Unresolved reference` 的本质是 **Kotlin 编译器在编译 `CydPluginDemoPlugin.kt` 时，找不到 `CydPluginDemoJNI` 对应的 `.class` 文件**。因此，首先要确认 `CydPluginDemoJNI` 自身是否被成功编译：

检查编译输出目录


   `CydPluginDemoJNI`编译后的 `.class`文件是否存在：

   路径：

   ```xml
   cyd_plugin_demo/plugin/build/intermediates/javac/release/classes/com/xiaomi/taiyi/plugin/cydplugindemo/
   ```

   - 若存在 `CydPluginDemoJNI.class`：说明该类编译成功，问题出在引用逻辑（如类名大小写、导入语句等细节）。
   - 若不存在：说明 `CydPluginDemoJNI` 自身编译失败，导致无法被引用（重点排查此类问题）。

**具体做法：**

注释掉`CydPluginDemoPlugin.kt`中的对`CydPluginDemoJNI`的引用，重新编译，就可以看到`CydPluginDemoJNI`为什么会编译失败，针对问题进行解决

## 3.Unresolved reference 'BuildConfig'.

### **`BuildConfig` 未生成**

BuildConfig` 是由 Android Gradle Plugin (AGP) 自动生成的，默认在 **构建时** 生成，生成路径为：
`build/generated/source/buildConfig/<buildType>/<packageName>/BuildConfig.java


若未生成，可能的原因：

- **模块类型配置问题**：`BuildConfig` 仅在 Android 应用模块（`com.android.application`）或库模块（`com.android.library`）中自动生成。若你的模块不是 Android 模块（如纯 Java/Kotlin 模块），AGP 不会生成该类。
- **构建任务未执行**：需先执行 `build` 或 `generateBuildConfig` 任务触发生成。
